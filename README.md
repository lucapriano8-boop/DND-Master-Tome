# DND Master Tome

Consultazione rapida per il Dungeon Master della campagna **Isola di Sanguis e Lux**.

Sito: https://lucapriano8-boop.github.io/DND-Master-Tome/

## Struttura

- `index.html`: pagina principale
- `css/style.css`: grafica
- `js/data.js`: **tutto il testo della campagna**, trascritto parola per parola dal PDF
- `js/app.js`: costruisce le schede e i collegamenti a partire da `data.js`

Per modificare o aggiungere contenuti si cambia solo `js/data.js`.
